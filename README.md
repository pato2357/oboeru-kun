# おぼえるくん

ニックネームから本名を覚える、ブラウザ内で完結するWebアプリです。

## 起動

`index.html` をブラウザで開くと使えます。ローカルプレビューは次のコマンドでも起動できます。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:4173 を開いてください。インストール・ビルドは不要です。

## 使い方

1. 「人を登録する」でニックネームと本名を入力します。
2. カードをタップして本名を表示します。
3. 覚えていたら右へ、わからなければ左へスワイプします。ボタンでも操作できます。
4. 左に送ったカードは末尾に戻り、全員覚えるまで繰り返せます。

キーボードでは、カードにフォーカスして Enter / Space で答えを表示し、左右矢印キーで仕分けできます。「ひとつ前に戻す」は同じ画面を開いている間の直近100操作を取り消します。

## 保存とプライバシー

- 登録データと練習の進捗は、このブラウザの localStorage（`oboeru-kun-v1`）だけに保存します。
- API、サーバーへのデータ送信、分析ツール、Cookie、外部フォント、CDN、外部ライブラリは使用しません。
- CSP の `connect-src 'none'` で通信APIによる外部送信を禁止しています。
- インターネット接続なしで使用できます。ローカルHTTPサーバーを使う場合も、名前を送信する処理はありません。
- 同じ端末・ブラウザ・URLでのみ続きから再開できます。`file:` URLの保存挙動はブラウザに依存するため、安定して保存したい場合は上記のローカルプレビューを使ってください。
- シークレットモード終了、ブラウザデータ消去、端末の故障などでデータが失われます。他の端末との同期はありません。
- 「登録した人」から個別編集・削除、全データ削除ができます。ブラウザを共有する人は保存内容を閲覧できるため、個人のブラウザで使ってください。
